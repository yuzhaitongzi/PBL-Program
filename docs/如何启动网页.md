# 如何重新打开网页

## 最省事的方式

打开访达，进入文件夹：

```
/Users/lightic/Documents/电路 AI 工作台/et-platform
```

**双击 `启动网页.command`**。会弹出一个终端窗口，等它显示 Ready 之后，
在浏览器打开：

```
http://localhost:3100
```

关闭服务：在那个终端窗口按 `Control + C`；或者直接关掉终端窗口。

---

## 如果双击没反应

第一次双击可能会提示「无法打开，因为它来自身份不明的开发者」。
处理方法：在文件上点右键 → 打开 → 仍要打开。

或者在「终端」里执行：

```bash
chmod +x "/Users/lightic/Documents/电路 AI 工作台/et-platform/启动网页.command"
```

---

## 用终端启动

打开「终端」应用，粘贴：

```bash
cd "/Users/lightic/Documents/电路 AI 工作台/et-platform"
pnpm dev
```

然后浏览器打开 http://localhost:3100

---

## 重要提醒

**端口必须保持 3100。** 教师端编辑的资源、题库，以及诊断记录、课堂快测、
预习任务、作业和补练记录，目前都保存在浏览器本地存储里，而本地存储是按
「地址 + 端口」隔离的。换成 3000 或其他端口，之前的数据就看不到了。

**换浏览器或清除浏览器数据会丢失这些内容。** 接入数据库后会改为服务端保存。
