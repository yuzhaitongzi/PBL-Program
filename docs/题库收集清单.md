# 《电工技术》题库收集清单

用途：为三旋翼 PBL 智能体平台提供题目，支撑基础诊断、课堂快测、作业批改、个性化补练四个环节。

---

## 一、需要下载/收集的内容

### 1. 历年作业与试卷（优先级最高）

向课程负责人苏圣超老师索取，这是最贴合本校教学、零成本、马上能用的来源：

- [ ] 近 3~5 年的课后作业及参考答案
- [ ] 近 3~5 年的期中、期末试卷及参考答案
- [ ] 已有的随堂小测、单元测验
- [ ] 若已有在线课程（学银在线 / 超星 / 雨课堂等）的测验题，一并导出
- [ ] 每道题最好能标注：所属章节、对应知识点、难度、题型

### 2. 教材配套习题

- [ ] 教材各章后的「习题 1~习题 7」（现成，与章节一一对应）
- [ ] 配套的《学习指导与习题解答》（若有）
- [ ] 教师用书中的补充习题

### 3. 学校平台资源库

如果学校已采购以下平台的题库，可合规导出使用：

- [ ] 超星学习通 / 泛雅题库
- [ ] 雨课堂题库
- [ ] 学银在线、智慧树上《电工学》《电工技术》课程的测验题
- [ ] 中国大学 MOOC 上同类课程的练习题（仅作参考，注意授权）

建议先问一句教务处或图书馆：学校是否已购买题库类资源，有的话能省下大量整理工作。

## 二、每道题需要记录的字段

整理成 Excel 或 Word 都行，字段如下：

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| 题号 | 唯一编号 | Q1001 |
| 章节 | 所属章节 | 第 1 章 1.5 节 |
| 知识点 | 对应知识点标签 | 戴维南定理 |
| 题型 | 单选 / 多选 / 判断 / 填空 / 计算 | 单选 |
| 题干 | 题目内容 | …… |
| 选项 | 选择题的选项 | A… B… C… D… |
| 答案 | 正确答案 | B |
| 解析 | 解题过程 | 由戴维南定理…… |
| 难度 | 易 / 中 / 难 | 中 |
| 来源 | 历年试卷 / 教材习题 / 自编 | 2024 期末 A 卷 |
| 适用专业 | 全部 / 机电类 / 化工材料类 | 全部 |

其中**章节、知识点、题型、答案**四项是必需的，缺了系统就没法按知识点组卷和做错因归因。

## 三、可以直接发给苏老师的话

> 苏老师您好，为了做课程平台的题库，想跟您要几样材料：
>
> 一是近几年的作业和期末考试卷，最好带参考答案；二是您平时用的随堂小测或单元测验；三是如果有教材配套的习题解答，也麻烦一并给我。
>
> 整理格式不用很严格，Word 或 PDF 扫描件都可以，我能自己录入。如果方便的话，麻烦在每道题旁边标注一下是哪一章、考的是哪个知识点，这样能直接接进平台，用来做课前诊断和课后补练。另外想请问学校有没有买题库存平台的账号（比如超星、雨课堂、学银在线），如果有的话可以用现成的。

## 四、若上述来源都不足：AI 生成 + 教师审核

平台已按知识点标签建好 44 节的内容结构，可以据此生成一批题目作为起步：

- 每个知识点生成 1~2 题，覆盖全部知识点
- 生成的题目统一标记来源为「AI 生成 · 待审核」，由任课教师逐条审核后才进入正式题库
- 审核通过后转为「教师确认」，未通过的直接删除或修改

这条路的定位是**填补空白**，不能替代前三个来源，尤其是考试类题目仍应以历年试题为准。
